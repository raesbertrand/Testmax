# Testmax
## commandes à taper dans le salon discord
## lister les membres
affiche les membres enregistrés
‎/list_registered_names‎

### register name
ajoute un membre
/register_name 1234567890 MonNomTacticus

Cela va enregistrer ce lien dans usernames_<guildId>.json.

### unregister name
supprime un membre

/unregister_name MonNomTacticus
ou
/unregister_name 1234567890
